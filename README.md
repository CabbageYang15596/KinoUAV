## Overview

This is the official repository for **KinoUAV: A Benchmark for Safe and Stable UAV Vision-Language Navigation with Kinodynamic Modeling**.

KinoUAV introduces a benchmark for safe and stable UAV vision-language navigation. It combines hierarchical kinodynamic trajectory generation, directional free-space distance (DFD) annotations, and a hierarchical navigation framework. The benchmark adopts a Cruise–Seek task, in which a UAV first navigates to the target region and then searches for the target.
